# FixyOffice downloads

Installers for **FixyOffice by Fixholics** — a free office suite: documents, spreadsheets, presentations and PDF tools.
Works offline; sign in with Google or Apple; optional backup to your own Google Drive. No ads, no paywall.

- **Windows:** download `FixyOffice-Setup-<version>.exe` from the [latest release](../../releases/latest) (or the portable `.exe` that runs without installing). The app updates itself from this page.
- **Web, Mac, iPhone/iPad, Android:** https://fixyoffice.vercel.app (install guide: https://fixyoffice.vercel.app/install)

Windows may show a SmartScreen warning for a new publisher: choose **More info → Run anyway**.

This repository only holds release files; the app's source code is private. Made by [Fixholics](https://fixholics.com/products/).
